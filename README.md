# ガチョウの逆襲

> だってアヒルばっかりずるいじゃん!

世界中で愛されているアヒルたちを、1羽のガチョウが駆逐していく、1分間のブラウザゲームです。

## 遊ぶ

**https://kentagogojp.github.io/goose-revenge/**

インストール不要。PC のブラウザ(キーボードとマウスが必要です)で開くだけで遊べます。

## 操作

| 操作 | 内容 |
|---|---|
| W / S | 前進 / 後退 |
| A / D | 左 / 右にスライド |
| マウス | ガチョウの向き |
| 左クリック | 首を伸ばしてつつく |
| ESC | 途中終了(スタート画面へ) |
| M | 効果音のオン / オフ |
| スペース | スタート / 終了画面からスタート画面へ |

## ルール

- 制限時間は1分。何アヒル駆逐できるかを競います。
- アヒルは1〜5羽の群れで行動し、近づくとそれぞれ別の方向に逃げます。
- 大きな白いアヒルは5回つつくと倒せて、5アヒル分です。
- 木と岩もつつくと壊せます(ポイントなし)。
- 最高得点は、遊んだブラウザの中に名前と一緒に保存されます。

## 仕組み

HTML + CSS + JavaScript だけで作っています。外部のライブラリや通信、音声・画像ファイルは使っていません(効果音はブラウザ上で合成)。

[Claude Code](https://claude.com/claude-code) の学習として作りました。
