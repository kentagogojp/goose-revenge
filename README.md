# ガチョウの逆襲

> だってアヒルばっかりずるいじゃん!

世界中で愛されているアヒルたちを、1羽のガチョウが駆逐していく、1分間のブラウザゲームです。

## 遊ぶ

**https://kentagogojp.github.io/goose-revenge/**

インストール不要。PC のブラウザ(キーボードとマウスが必要です)で開くだけで遊べます。

## 操作

| 操作 | 内容 |
|---|---|
| W / S | 前進 / 後退 |
| A / D | 左 / 右にスライド |
| マウス | ガチョウの向き |
| 左クリック | 首を伸ばしてつつく |
| ESC | 途中終了(スタート画面へ) |
| M | 効果音のオン / オフ |
| スペース | スタート / 終了画面からスタート画面へ |
| X | 終了画面で、結果をXに投稿する画面を開く |

## ルール

- 制限時間は1分。何アヒル駆逐できるかを競います。
- アヒルは1〜5羽の群れで行動し、近づくとそれぞれ別の方向に逃げます。
- 大きな白いアヒルは5回つつくと倒せて、5アヒル分です。
- 木と岩もつつくと壊せます(ポイントなし)。
- 最高得点は、遊んだブラウザの中に名前と一緒に保存されます(ランキングはありません)。
- 終了画面の「𝕏 で結果をシェア」で、結果(ゲーム名・名前・得点・URL・ #GooseRevenge)を入れた投稿画面が開きます。自動では投稿されません。

## 仕組み

HTML + CSS + JavaScript だけで作っています。外部のライブラリや音声ファイルは使わず(効果音はブラウザ上で合成)、ゲーム中に外部と通信することもありません。通信が起きるのは、シェアボタンを押して X の投稿画面を開いたときだけです。
